#  Sfiral-ResNet: Сфиральная сверточная нейросеть с сохранением топологической фазы

Данный проект представляет собой экспериментальную модификацию 20-слойной архитектуры ResNet на базе датасета CIFAR-10. В стандартную структуру остаточных блоков интегрированы физические и математические принципы Сфирали — открытой комплементарной топологической системы с зеркально-антисимметричными хиральными витками и плавным ламинарным S-переходом фазовой инверсии.

###  Архитектурные особенности

В отличие от классического ResNet, использующего линейное суммирование шорткатов ($y = F(x) + x$) с потерей части фазовой энергии, Sfiral-ResNet реализует принципы топологического фолдинга:
* **Хиральное разделение:** Поток данных внутри блока разделяется на зеркально-антисимметричные компоненты (левый и правый витки).
* **Мягкая фазовая инверсия:** Вместо мгновенных скачков используется ламинарный S-переход, обеспечивающий сохранение более 99.6% фазовой энергии без разрыва потока.
* **Строгое равенство параметров:** Сохранено точное соответствие базовому аналогу (272,474 обучаемых параметров), что делает прямое сравнение абсолютно честным.

###  Результаты обучения и бенчмарки

* **Ускорение на старте:** Уже на 1-й эпохе сфиральная модель показала точность валидации 48.69% (против 43.40% у классического аналога), обеспечив прирост +5.29% за счет сохранения фазовой энергии.
* **Пиковая точность:** Стабильная зона генерализации достигает 86.81% валидационной точности на длинной дистанции (полный цикл на 50 эпох).

Подробные логи, графики и сравнительные таблицы по эпохам доступны в файле [RESULTS.md](RESULTS.md).
